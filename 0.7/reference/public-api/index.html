    title: Public API Reference — AnyCode Python Framework description: API reference for the AnyCode Python framework: orchestrator, TaskSpec, agent and team config models, result types, tool registry, and provider adapters. keywords: AnyCode, AnyCode Python, public API, orchestrator, TaskSpec, AgentConfig, TeamConfig, ToolRegistry, provider adapter, mkdocstrings

    Public API¶

    This page is the stable, importable surface of the AnyCode Python framework, generated directly from source docstrings so signatures and fields stay in sync with the code. Use it to look up exact arguments, methods, and model attributes.

    Every symbol below is exported from the package root, so from anycode import AnyCode, TaskSpec, AgentConfig is the supported import style. Treat internal submodule paths as private. The compatibility policy defines additive patch releases, pre-1.0 breaking changes, and persisted-format guarantees.

    New here? Read the concepts first

    This reference lists signatures, not tutorials. For how these pieces fit together, start with the Concepts overview, then the YAML config guide and Tools guide.

    Core classes¶

    The orchestrator is the primary entry point: configure it once, then build agents, assemble teams, and run tasks. TaskSpec describes a single unit of work handed to an agent or team.

    anycode.tools.executor.ToolExecutor ¶

    Validates inputs via Pydantic then invokes tools, with semaphore-bounded batch execution.

    Side-effecting tools use atomic claims to prevent duplicate execution. The in-memory store coordinates one process; the SQLite store persists claims and results across restarts.

    anycode.tools.idempotency.ToolIdempotencyStore ¶

    Provider API¶

    create_adapter resolves the right provider adapter for a configured model — Anthropic, OpenAI, Google, Bedrock, Azure OpenAI, Ollama, or a plugin-registered backend — giving the runtime a uniform interface across providers.

    anycode.providers.adapter.create_adapter async ¶

    create_adapter(
    provider: str,
    api_key: str | None = None,
    *,
    base_url: str | None = None,
    endpoint: str | None = None,
    api_version: str | None = None,
    region: str | None = None,
    profile: str | None = None,
    model: str | None = None,
    resilience: ProviderResilienceConfig | None = None,
) -> LLMAdapter

    Lazy-load the provider SDK (or plugin factory) and return an adapter instance.

    Adapters are wrapped in ResilientAdapter (retry/backoff, deadlines, circuit breaker) by default; pass resilience=ProviderResilienceConfig(enabled=False) for the raw adapter.

    anycode.providers.resilience.ProviderCapacityLimiter ¶

    Cancellation-safe concurrency and request-rate gate for provider attempts.

    anycode.types.ProviderResilienceConfig ¶

    Capacity, retry, deadline, and circuit-breaker settings for an LLM provider.

    Durable storage APIs¶

    AgentRunner accepts any backend satisfying RunStore. The built-in filesystem backend adds local atomic writes, protected-payload envelopes, checkpoint recovery, and terminal-run retention.

    anycode.runstore.protocol.RunStore ¶

    Persistence operations required by durable runners and schedulers.

    anycode.runstore.protocol.RunPayloadProtector ¶

    Protects serialized run-store bytes, typically using envelope encryption.

    anycode.runstore.store.FilesystemRunStore ¶

    Durable per-run persistence on the local filesystem (stdlib only).

    pause_run ¶

    pause_run(run_id: str, wake: WakeCondition) -> RunRecord

    Pause a run with a persisted wake condition; the process may exit.

    due_wakes ¶

    due_wakes(
    *, tolerance_seconds: float = 30.0
) -> list[RunRecord]

    Paused runs whose timed wake condition is due (clock-skew tolerant).

    on_approval and manual wakes have no timestamp and never auto-fire; they resume through their own signal (approval response, operator).

    try_acquire_sweep_lock ¶

    try_acquire_sweep_lock(
    run_id: str, *, stale_after_seconds: float = 60.0
) -> bool

    Per-run lock so two concurrent sweeps cannot double-resume a run.

    Lock files older than stale_after_seconds are treated as leftovers from a dead sweep and taken over.

    mark_interrupted_runs ¶

    mark_interrupted_runs(
    stale_after_seconds: float,
) -> list[str]

    Mark running runs with a stale heartbeat as interrupted.

    Call on startup so a crashed process never leaves phantom running states behind. Returns the run ids that were transitioned.
